# Security Policy

Security fixes are applied to the latest default-branch revision.

Do not open a public issue for a suspected vulnerability. Use GitHub private
vulnerability reporting or contact the repository owner privately. Include the
affected revision, reproduction steps, likely impact, and suggested remediation
without including real customer data or active credentials. Publication should
wait until a fix and reasonable deployment window are available.

See [docs/SECURITY.md](docs/SECURITY.md) for the implementation security model.
